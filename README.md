# e-plantShopping

## Project Name
Paradise Nursery Shopping Cart

## Overview
e-plantShopping is a React application for an online plant shop called Paradise Nursery. 
It allows users to browse house plants organized by category (e.g., Aromatic Plants, 
Medicinal Plants), add plants to a shopping cart, adjust quantities, and view total costs.

## Features
- Landing page with a "Get Started" button
- Navigation bar with links to Home, Plants, and Cart
- Product listing with plant cards (image, name, description, cost, Add to Cart)
- Shopping cart with quantity controls and a Delete button
- Continue Shopping and Checkout buttons

## Tech Stack
- React
- React Router
- Redux Toolkit (for cart state)
- CSS
